## Automation roadmap

- **CI is now the gate** — keep it green; treat a red `dev` run as a stop.
  Add: functions `lint`, functions coverage, `web/functions/src` to depcruise.
- **Pyramid target:** pure core + functions logic (unit, fast) ≫ hooks via
  `renderHook` in web (fetch stubbed) ≫ emulator (rules, quota, adapters) ≫
  Maestro smoke (nightly, currently unverified).
- **AI-dependent tests:** never hit the live API in CI. Stub `fetch` on the
  client (see `useMochiAgent.test.ts`); inject/mock the Anthropic client on the
  server with recorded fixtures (tool_use, end_turn, malformed args, overload,
  `max_tokens` stop). Keep one shared wire-fixture set for callable responses
  (`{result}`, 429 RESOURCE_EXHAUSTED, 429 empty, 400 FAILED_PRECONDITION) run
  against both clients. Live smoke: 1–2 manual calls before a release. Prompt
  regressions: an opt-in offline eval on Haiku, not in CI.
